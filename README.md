# Paradise Soul

Prodajna stranica za domaći sok, soseve, sušeni i sveži paradajz.

## Objava na GitHub Pages

1. Napravi novi javni repozitorijum na github.com, na primer `paradise-soul`.
2. Ubaci sadržaj ovog foldera u koren repozitorijuma: `index.html`, folder `assets` i fajl `.nojekyll`.
3. U repozitorijumu otvori Settings > Pages.
4. Pod "Build and deployment" izaberi "Deploy from a branch", grana `main`, folder `/ (root)`, pa Save.
5. Posle minut-dva sajt je na adresi `https://<tvoje-korisnicko-ime>.github.io/paradise-soul/`.

Sopstveni domen se dodaje na istoj stranici, u polju "Custom domain".

## Napomena

Formular za rezervaciju proverava unos i prikazuje potvrdu, ali podatke još nigde ne šalje.
GitHub Pages hostuje samo statične fajlove, pa formular treba povezati sa servisom kao što je Formspree.
